# Repository task routing

These rules apply to tasks started from the repository root.

- For any work under `projects/fitness-ledger`, read and follow
  `projects/fitness-ledger/AGENTS.md` before reviewing or editing files.
- Do not assume that an automatically created detached Worktree is based on the
  current formal product baseline. Run the project's live status command and
  compare `HEAD`, local `main`, and `origin/main` first.
- Project-specific instructions override this routing file within their scope.
